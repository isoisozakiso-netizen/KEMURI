# Roadmap

A rough, evolving plan. Items are not commitments and may change.

## Done

- Restaurant search (Hotpepper) with genre / budget / open-now / smoking filters
- Smoking-style voting per shop
- Manually added shops (with geocoding)
- Map view with vote-colored pins
- Distance sort (geolocation)
- Comments and photo upload (Cloudflare KV)
- Share links with OGP
- Gacha ("decide for me") feature
